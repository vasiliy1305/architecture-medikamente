# Task6 — MVP (очень просто)

## Что делаем
Перед загрузкой в DWH:
1) автоматически понимаем схему (schema detect),
2) классифицируем поля простыми правилами (PII/секреты),
3) применяем действие: **mask** или **quarantine**,
4) грузим в DWH только разрешённые зоны.

## Поток
Data Sources → Raw Storage → Schema Detect → Classifier → Transform → Zones → DWH

## Зоны (слои)
- **Curated**: безопасные данные для аналитики
- **Confidential**: ограниченный доступ
- **Quarantine**: низкая уверенность / спорные поля (ручная проверка)

## Метрики (MVP)
- **Coverage**: % полей с классом (confidence ≥ порога)
- **Quarantine rate**: % данных в карантине
- **FN rate** для confidential: пропуски конфиденциальных данных (критично)

## Масштабирование (MVP)
- обработка батчами + параллельные воркеры классификации/трансформации
