1. Реестр данных (As-Is)
1.1 Персональные данные пациента (базовые PII)

- ФИО

- Дата рождения

- Телефон

- Email

Хранение (As-Is): Excel-файлы на общем диске.

1.2 Персональные данные пациента (расширенная анкета)

- Адрес регистрации

- Место работы / учёбы

- Сведения о хронических заболеваниях

Хранение (As-Is): Excel-файлы, возможные сканы (JPG/PDF) на общем диске.

1.3 Медицинские данные (чувствительные персональные данные)

- Медицинские карты

- Заключения врачей

- Результаты анализов

Хранение (As-Is): Excel-файлы, сканы (JPG/PDF) на файловом сервере.

1.4 Финансовые данные пациента

- Данные об оплате услуг

- Чеки ККМ

- Договоры / контракты

Хранение (As-Is):

1С:Бухгалтерия предприятия (файловый режим)

Частично дублируются в Excel

1.5 Учётные данные сотрудников (доступ к системам)

- Доменные учётные записи (AD)

- Роли и группы доступа

- Корпоративная почта

Хранение (As-Is):

Active Directory

Exchange Server / Outlook

1.6 Данные по ТМЦ (бизнес-критичные)

- Остатки на складе

- Закупки оборудования

- Учёт движения ТМЦ

Хранение (As-Is):

1С:Торговля и склад (файловый режим)

1.7 Технические данные и следы действий

- События доступа к файлам

- Почтовые сообщения

- Системные журналы (ограниченно)

Хранение (As-Is):

Exchange Server

Windows Server (минимальный аудит)

Файловый сервер
