Проблемные зоны (As-Is)
1. Отсутствие централизованной системы хранения медицинских данных

Медкарты хранятся в Excel, JPG, PDF.

Нет единого реестра и контроля версий.

Нет контроля целостности данных.

Риск: утечка, подмена, несанкционированное копирование.

2. Хранение PII в Excel на общем диске

Файлы доступны через общий сетевой ресурс.

Нет разграничения доступа на уровне строк/пациентов.

Нет шифрования на уровне файлов.

Риск: любой сотрудник с доступом к диску может получить полный массив данных.

3. Отсутствие аудита действий пользователей

Нет журналирования доступа к медкартам.

Нет контроля скачивания/копирования файлов.

Нет мониторинга аномального поведения.

Риск: невозможно выявить факт утечки или виновное лицо.

4. Двойной учёт оплат (Excel + 1С)

Расхождение данных.

Повышенный риск ошибок.

Дополнительные копии PII.

Риск: неконсистентность данных и увеличение площади атаки.

5. 1С в файловом режиме

Файлы базы данных физически доступны на сервере.

Нет изоляции на уровне БД-сервера.

Повышенный риск компрометации.

Риск: при доступе к файловому серверу возможно получение всей базы.

6. Отсутствие Data Classification и тегирования

Нет разделения данных по уровням чувствительности в системах.

Нет автоматической проверки использования чувствительных данных.

Риск: конфиденциальные данные обрабатываются как обычные.

7. Отсутствие сегментации сети

Сервер находится в том же здании.

Нет выделенной зоны для чувствительных данных.

Нет DMZ для будущих внешних сервисов.

Риск: при компрометации одного узла атакующий получает доступ ко всей инфраструктуре.

8. Недостаточные меры защиты PII по требованиям законодательства РФ

Нет механизма удаления данных по запросу субъекта.

Нет формализованной политики обработки ПДн.

Нет контроля трансграничной передачи данных.

Риск: юридические и репутационные последствия.
